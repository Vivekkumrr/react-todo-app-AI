# Noteify

A simple Notes & Todo task manager application built with React and Vite.

## Getting Started

### 1. Clone the Repository
```bash
git clone https://github.com/Vivekkumrr/react-todo-app-AI.git
cd react-todo-app-AI
```

### 2. Go to the Frontend Folder
```bash
cd frontend
```

### 3. Install Dependencies
```bash
npm install
```

### 4. Start the Local Server
```bash
npm run dev
```

Open `http://localhost:5173/` in your browser to run the app.
